# TF 卡槽侧面修正

日期：2026-11-13。

- 共享外壳的 TF 卡槽从 X 正侧移到 X 负侧，保持高度、长度与接口位置不变。默认 6pin 接线视角由近侧不透明外壳遮挡，不再错误显示卡槽。
- TF 插卡动画同时移动到对应侧面并反转进卡方向；专用 TF 视角仍可展示操作。
- 三个模型使用入口添加共享几何内容版本号，并更新页面脚本与嵌入页缓存版本，避免旧浏览器缓存保留反向卡槽。
- 不修改设备接口、引脚定义、固件或已有未提交的品牌标志等工作。

验证：Sphinx 严格构建、SDK 快照、站点资源缓存、发布安全、文档链接通过；浏览器检查卡槽全部顶点位于负 X 侧、默认接线视角射线先命中近侧外壳、插卡方向一致；1440/390/320px 的 6pin、USB、TF、回到 6pin 共 12 个视图通过。人工核对 1440px 接线截图，箭头所指的近侧不再显示卡槽。截图与 report.json 随本记录归档。属于网页模型验证，不是硬件验收。
