故障排查
========

先区分发生在哪一层
------------------

按“USB 网络 → 设备网页 → 服务状态 → 数据流 → 定位有效性 → 下游融合”的顺序排查。
不要因为最后看不到轨迹，就直接重标定或反复更新固件。每次只改变一个条件，
保留更改前后的状态和错误码。

设备网页打不开
--------------

1. 检查供电和数据线，换一根确认支持数据的 USB 线。
2. 检查系统是否识别 USB 网络适配器，而不是仅显示充电。
3. 确认电脑该网卡自动获取地址，并与设备处于同一网段。
4. 在地址栏明确输入 ``http://192.168.11.1/``，不要使用公网文档网址代替。
5. 如果改过网段，使用保存后的地址，检查其他网卡或路由是否冲突。
6. 公网快速开始检测失败时，直接打开设备地址，区分浏览器策略与真实设备故障。

能打开网页，但没有图像
----------------------

确认连接状态，关闭其他浏览器标签页和不需要的外部订阅。
``STREAM_LIMIT`` 表示连接额度已满，``PREVIEW_UNAVAILABLE``、``GRAY_NOT_READY``
等表示对应源未就绪。服务返回成功之后再断流，也可能没有额外 JSON 错误。

只有 H.265 不显示时，先检查浏览器支持，明确选择 MJPEG/H.264 做对照。
固件或页面更新后显示不一致，可重新加载页面，同时核对设备网关与应用版本。

有图像，但没有轨迹
------------------

先检查 VIO 是否 running，再看 tracking。initializing 时按提示提供有效运动和纹理；
invalid 时检查遮挡、模糊、振动、动态物体与标定；null 表示未知或过期，不是位于原点。

读取标定来源。如果是 default 或提示 CALIBRATION_REQUIRED，
默认参数只是名义值，不保证当前设备精度。参数损坏应处理配置，
不能期待重启自动换成默认值。

方向、尺度或速度不符合预期
--------------------------

核对通道与参考点：HTTP 里程计是 IMU 原点，串口输出应用安装补偿。
检查是否重复施加杆臂，是否混用相机轴、机器人轴及 FLU/FRD 与世界坐标。

标定板尺寸会影响尺度，确认 cm、mm、m 换算正确，A—B 没有误量为纸张白边。
不同分辨率也不能直接套用同一组内参。
IMU 静止时加速度含重力；线速度在 IMU 本体系表达，与世界位置差分比较前需转换坐标。

保存失败或看起来未生效
----------------------

标定参数需释放 VIO、录制、预检、深度和采集；安装补偿允许运行中保存，
但下次 VIO 启动采用；开机设置下次整机启动处理。

CONFIG_SAVE_FAILED、CALIBRATION_SAVE_FAILED 或超时可能只是保存结果未确认。
先回读，不立即重复提交。多个页面同时编辑时检查是否被后一次保存覆盖。

TF 卡不就绪或录制不完整
-----------------------

检查卡状态、空间、文件系统和是否仍在挂载检查。unmounted 不简单等于没有卡，
不要自动格式化有数据的卡。录制结束按本次 ID 查看 result，不以 idle 判断成功。

storage_full 表示空间不足，write_failed 表示写入失败，queue_overflow 表示积压，
data_gap_or_source_error 表示连续性或源错误。包含里程计时还需确认 VIO 有有效输出。

先备份可下载前缀，再按实际配置重做预检。减轻并发负载有助于定位问题，
一次短测通过不等于长期稳定；risk 不等于失败，也不等于无风险通过。

浏览器数据不见了
----------------

浏览器录制只在当前页面内存。刷新、关闭或手机系统回收后无法从 TF 卡找回，
因为它没有写入 TF。以后停止后及时下载，并确认文件实际存在。

飞控有心跳却没有融合
--------------------

确认实际接线端口、目标飞控、MAVLink 2 和安装参考点。
参数读取不证明写入成功，回读一致不证明融合。
在地面站检查估计器外部定位来源，用可控运动核对方向。
通信超时先查询结果，避免重复写参数或发重启命令。

更新失败或维护状态
------------------

UPDATE_BUSY 时结束相关任务；包不兼容时核对硬件、布局和签名。
reboot_required 要求按流程重启；recovery_required 不应通过反复安装清除。
UPDATE_BOOT_FAILED 时先核对回退后的版本，详见 :doc:`maintenance`。

反馈问题时提供什么
------------------

* 设备软件版本、网关版本、浏览器和操作系统。
* 连接方式、问题发生时间、是否能重复，以及简短操作顺序。
* 页面截图、实际错误码、任务/录制 ID，必要时提供对应数据包和标定来源。
* 同时开启的录制、深度、订阅，以及刚修改的安装、网段、固件、卡或参数。

设备应用不生成运行日志，不需要寻找“日志下载”入口。
保留原始错误码，不把个人网络凭据或无关数据加入报告。
