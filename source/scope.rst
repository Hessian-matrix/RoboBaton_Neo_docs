适用范围与版本说明
==================

文档依据
--------

整理日期为 2026-11-11。应用源码参考提交为
``c2fad336b539f01994c9bf0f8076a0d2a84bf20e`` （czr_public）。
产品外观、规格和快速开始采用同仓库已确认页面；
HTTP 契约来源及校验值见 :doc:`api-reference`。

这些描述不自动证明设备上已安装同一构建。历史固件可能在路径、卡支持、
网络地址或更新布局上不同，操作前核对运行版本，使用成套的网关、网页和应用。

公开功能边界
------------

当前公开版提供 VIO、图像/IMU、相对深度、设备采集标定、TF/浏览器录制、
数据管理、安装补偿、按键、网络、开机策略、飞控接入和本地签名包更新。

内部回放、离线标定包/EuRoC 导入、开发求解入口、运行日志页面和双版本构建
不属于当前公开产品。公开数据包下载不等于提供算法回放功能。

如何理解验证描述
----------------

* 源码/契约支持：当前代码定义了此行为，仍受设备软硬件版本影响。
* 本地或浏览器测试：验证页面、协议或模拟交互，不代替实机精度和飞控融合。
* 历史实测：只对应注明的软件、硬件、数据集和负载，不自动扩大到新版本。
* 产品演示：模型、轨迹动画、波形和接线示意不是设备当前输出。

网站性能数据使用 2026-10-17 的 EuRoC 11 条和 UZH-FPV 16 条历史基准。
误差采用 SE(3) 对齐、无尺度修正，归一化为 ATE RMSE / 对应真值路程。
初始化延迟指数据时间轴上的首个有效位姿延迟，不是设备开机耗时。

“出厂已标定”适用于保有匹配出厂参数的设备。source=default 是名义回退，
不能视为出厂参数；source=saved 也需要确认来源匹配。

系统与发布
----------

FAT32/exFAT 与 A/B 更新需要配套系统，不能假设旧系统具有这些能力。
普通 OTA 不迁移分区布局，具体卡容量和持续写速需实卡测试。
飞控兼容性取决于固件、机型和估计器配置；相对深度不提供米制测距保证。

推送仓库后 GitHub Pages 和 Read the Docs 各自构建，完成时间可能不同。
一边成功不代表另一边已上线。本次文档不修改设备接口或算法，
也不代表全部功能重新完成实机验收。
