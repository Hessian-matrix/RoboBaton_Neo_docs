网络、按键与开机设置
====================

修改设备网络
------------

设备设置中的网络选项用于修改 USB 网段。地址形如 ``192.168.N.1``，
N 可设置为 11–255 的整数，默认 11。选择一个不与电脑其他网络冲突的网段。

1. 结束依赖稳定网络的采集，确认没有更新或重启操作。
2. 记录当前地址和目标地址。
3. 提交修改，等待网络重建；电脑 USB 网卡应保持自动获取 IP。
4. 使用新地址重新打开设备页面。
5. 重新读取网络配置，核对实际生效网段。

修改后短暂断线是预期行为。返回受理或连接中断不等于修改完成。
如果无法访问新地址，再检查电脑地址及旧地址，不连续重复提交。
固定配置在旧网段的电脑不会自动跟随设备变化。

网络切换不主动停止板端 VIO 或 TF 录制，但会打断预览和浏览器采集等外部连接。
配置成功后保存到设备，下次开机使用已保存网段。

实体按键动作
------------

在设备设置的按键页读取当前配置，再设置短按、长按动作和 TF 录制通道。
可选动作包括不执行、VIO 启停、重启已运行的 VIO、TF 录制启停。
长按阈值为 1、2、3 或 5 秒。

默认配置为短按不执行、长按录制启停、阈值 2 秒、录制灰度和 IMU；
有历史配置的设备可能沿用已保存值，应以读取结果为准。

按键采用准备手势，避免误触：

1. 先短按并松开，进入准备状态，灯快闪。
2. 5 秒内开始第二次手势。
3. 第二次短按在松开时执行；第二次长按达到阈值时执行一次。
4. 继续按住或松手不会重复执行；没有准备的直接长按不执行任务。

保存新配置、任务切换或驱动连接异常等情况会取消准备状态。
如果动作被拒绝，先检查是否正在保存、预检、更新或执行其他命令，
不要通过反复长按绕过任务互斥。

按键录制固定保存到 TF 卡，其通道预设与网页当前的浏览器/TF 选项独立。
保存按键配置不会立即开始任务，录制中改预设也不会改变当前任务通道。
选择里程计时仍需先启动 VIO。

灯效与结果
----------

准备时快闪，长按阶段渐亮，初始化或保存阶段有慢闪反馈；
成功提示应对应实际操作结果，而不只是命令受理。
发生拒绝或失败时通过页面查看真实任务状态和错误码。
灯效是辅助反馈，不能代替检查录制结果完整性和定位有效状态。

开机自动启动 VIO
----------------

在实时 VIO 的开机设置中读取当前开关，选择是否启用并保存到设备。
页面回读一致后才确认保存；它改变的是下一次系统启动策略，不立即启停当前 VIO。
缺少配置时默认关闭。

每次系统启动最多自动尝试一次。驱动未就绪、其他任务占用或启动失败时
可能跳过，不持续重试；手动停止或异常退出后也不会因此自动拉起。
重新打开网页、重启设备服务不算新的整机启动。

该开关不会自动启动 TF 录制、深度或浏览器预览。
开机后仍应检查 VIO 的实际进程状态、tracking 与标定警告。

保存与生效速查
--------------

.. list-table:: 不同配置的生效时机
   :header-rows: 1
   :widths: 25 35 40

   * - 配置
     - 保存位置/持续性
     - 生效规则
   * - USB 网段
     - 设备持久保存
     - 切换网络并核对，之后重新连接
   * - 按键预设
     - 设备持久保存
     - 后续手势采用，不修改当前录制
   * - 开机 VIO 开关
     - 设备持久保存
     - 下次整机启动处理
   * - 安装补偿
     - 设备持久保存
     - 下次 VIO 启动/重启采用
   * - 标定参数
     - 设备持久保存
     - 空闲时保存，下次任务启动采用
   * - 彩图配置
     - 本次驱动运行
     - 应用后重建相应流，驱动重启不保留

多个页面同时编辑时可能互相覆盖。提交前重新读取关键配置，
保存失败或响应丢失时先回读确认，不把网页草稿当作设备真实状态。
