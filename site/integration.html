电脑串口
运行时选择 USB 转 TTL 模块
与设备串口配置保持一致。默认 921600，8N1，无流控。
网页运行需电脑 Chrome / Edge，选择 USB 转 TTL 模块。


下载 Windows 连接工具
打开工具并保持运行，再点击左侧连接。无需安装 Python，不修改设备。
其他系统与下载说明
当前免安装包支持 Windows x64；macOS / Linux 可用 Python 3 运行同份开源工具：python3 neo_connect.py --headless。
Windows 包未签名，系统可能提示未知发布者。查看 SHA256 · 运行库许可 · 查看源码
