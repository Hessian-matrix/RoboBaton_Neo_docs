参数与测试说明

* 接线依据 RoboBaton Neo 产品手册 V1.1 第 2、4 页（硬件 v1.5）。串口为 3.3 V LVTTL，不连接 RS-232。6 脚 VIN 输入 3.3–5 V；图示采用独立稳压电源，与飞控共地，不将未知飞控电源脚直接接入。手册说明 USB 与 6pin 同时供电时优先 USB、自动切换；实际接线前应核对硬件版本。1/2 脚同步信号为 1.8 V，不接 3.3 V 串口；外部触发输入仅从机模式有效，图示不宣称当前公开固件提供主从模式设置。

* 产品规格参考手册 V1.1 第 1、3、4 页：RGB 相机分辨率 1080×1280（宽×高）；USB 压缩图像 H.264/H.265/MJPEG 最高支持 60 fps，MJPEG 在 60 fps 时偶有丢帧。手册尚未给出输出分辨率与帧率的完整对应关系，不据此承诺所有配置均可全分辨率 60 fps。当前公开 HTTP 实现中，彩色输出 1080×1280、帧率可设，VIO 运行时上限 5 fps；独立未压缩灰度通道为 544×640、mono8、5 fps。IMU 默认多样本平均后约 200 Hz，包含重力响应、未扣除 VIO 偏置，不是未平均 FIFO 样本。HTTP 数据流采用 RBH1 封装。串口采用 MAVLink 2 ODOMETRY（331），最高约 30 Hz，受有效定位数据和波特率限制。

* 手机连接需支持 USB OTG / 主机模式及 NCM 或 RNDIS 网卡，并满足设备供电要求；兼容性取决于手机系统与驱动，不代表所有 Android 或 iPhone 均可直连。通过 USB 虚拟网络在浏览器访问设备页面。

* 接口依据当前公开版 API 文档，OpenAPI 下载为本地原型快照。HTTP 实时流使用 RBH1 二进制封装，不能直接当作普通 JSON 响应解析。默认地址为 192.168.11.1，配置后以实际地址为准。HTTP 里程计固定以 IMU 为参考；串口 ODOMETRY 应用安装补偿，两者不能直接混用。ArduPilot / PX4 为接入目标，实际定位融合须在对应飞控上验证。

* 运动峰值统计范围为本页 11 条 EuRoC、16 条 UZH-FPV 的真值覆盖时段，速度与角速度均为三轴向量模长。EuRoC 使用真值速度；FPV 使用真值位置按原始时间戳中心差分（端点单边差分），未平滑；角速度采用同一时段原始陀螺仪数据，未扣除零偏。最大速度分别出自 MH_04_difficult、outdoor_forward_5；最大角速度分别出自 MH_03_medium、indoor_forward_7。速度与角速度峰值不要求同时出现；这些数值说明数据集运动强度，不代表峰值时刻已验证定位精度或设备运动上限。下载逐序列运动统计

* VIO 指标来自 2026-10-17 历史算法基准（EuRoC 11 条、UZH-FPV 16 条），不代表当前固件重新实测。采用 SE(3) 对齐，不做尺度修正；归一化轨迹误差 = ATE RMSE / 对应评估区间真值路程 × 100%，主数值为各序列等权平均，非逐段漂移率。初始化时间采用数据时间轴上的首个有效位姿延迟，并非设备开机耗时：EuRoC 范围 0.50–4.60 s，FPV 范围 0.43–3.35 s。精度仅覆盖有真值匹配的区间；完成测试不等于全程无失跟或任意速度下的保证。下载逐序列数据

* < 1 ms 为所提供的 Kalibr 相机—IMU 时间标定结果，不等同于任意工况下的最大同步误差。时序图为原理示意。

* 惯性指标来自传感器原厂数据手册第10–11页，为典型值，非本机实测保证值。噪声密度条件：10 Hz、25°C、VDD/VDDIO 1.8 V；陀螺仪零偏温漂条件：−40°C 至 +85°C，板级特性依赖设计。零偏温漂不等于运行中零偏稳定性；后者需 Allan 方差等实测评估。官方资料

* 相机参数参考产品手册 V1.1：视场角依次为对角、水平、垂直方向；60 fps 指相机采集，并非所有工作模式下的图像外发帧率。IMU 当前默认输出约 200 Hz，采用多样本平均与窗口中心时间戳。图中视野和波形仅说明原理，不是精确光学投影或实测噪声结果。

* 尺寸与重量参考所提供的产品资料与称重照片。裸机重量 8.69 g，带壳重量 13.86 g；本页未重新称重。

* 裸机板体长宽为 40 × 20 mm，含镜头总高 19.5 mm；带壳外形为 43.8 × 23.8 × 21.6 mm，总高均包含镜头。镜头最大外径为 14 mm。三维模型为外观示意，不作为制造图纸。

* 裸机与带壳两种形式均支持 USB 供电。拖动模型可查看外观；运动原理演示使用模拟数据。
